## Projetos em destaque

### [Health Appointment System](https://github.com/ViniCarmo/health-appointment-system)
Sistema de agendamento hospitalar com **2 microsserviços** comunicando de forma assíncrona via **Apache Kafka**. Autenticação JWT com autorização por papel e por posse do recurso, histórico médico via GraphQL e Clean Architecture com 73 testes automatizados. Builds Docker multistage que reduziram as imagens em ~71%.  
*Projeto da Pós FIAP, aprovado com nota máxima.*

### [Finance API](https://github.com/ViniCarmo/financeControl)
API de gestão financeira **em produção na AWS (EC2 + RDS)**, com autenticação JWT, RBAC, isolamento de dados por usuário, resumos mensais e testes automatizados.

### [Payments API](https://github.com/ViniCarmo/PaymentsAPI) · *em desenvolvimento*
Sistema de pagamentos com microsserviços orientados a eventos, projetado para que nenhuma transação seja duplicada ou perdida: idempotência, Outbox Pattern, lock otimista e observabilidade com Prometheus e Grafana.
